# De¹ Frontend Examples

This repository includes examples of the De¹ frontend. You can view details in each subdirectory.


## 📁 Project Structure

```
de1-api-examples/
├── backend/          # Node.js/Express backend examples
├── frontend/         # React frontend examples  
└── README.md         # This file
```

## 🚀 Features

This project demonstrates the following De¹ APIs:

- **Swap API** - Cross-chain token swapping
- **Limit Order API** - Create and manage limit orders
- **DCA API** - Dollar Cost Averaging

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- Axios for API calls
- dotenv for environment variables

### Frontend
- React
- TypeScript
- Axios for API calls
- Tailwind CSS for styling

## 📚 Documentation

For detailed API documentation, visit: [De¹ API Docs](https://docs.de1.exchange)

## 🚀 Getting Started

### Backend Setup
```bash
cd backend
npm install
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
